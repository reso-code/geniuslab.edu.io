# منصة العلوم التفاعلية – الصف الثالث الابتدائي

## التشغيل
1. فك الضغط عن المجلد.
2. شغّل المنصة من خادم محلي (الأفضل) أو افتح `index.html` مباشرة.
   - مثال: داخل المجلد نفّذ `python3 -m http.server 8000` ثم افتح http://localhost:8000
   - لو فتحت الملف مباشرة (file://) ستعمل كل الأقسام، لكن التحميل التلقائي للكتاب من المجلد قد يمنعه المتصفح، وقتها اختر ملف الكتاب مرة واحدة من زر «اختر ملف الكتاب (PDF)».

## الملف الوحيد الناقص: الكتاب المدرسي
ملف الكتاب PDF (196 صفحة) غير مرفق لأنه لم يكن ضمن الملفات المقدّمة.
ضعه في **نفس مجلد index.html** بأحد الاسمين:
- `كتاب العلوم الثالث الابتدائي.pdf`
- `book.pdf`

فيفتح تلقائياً. أو اختره من داخل المنصة (يُحفظ في ذاكرة المتصفح).

## هيكل المشروع
- `index.html` — الصفحة الرئيسية (نفس HTML الأصلي)
- `js/app.js` — كل منطق المنصة (نفس JavaScript الأصلي، مع تغيير مسار PDF worker إلى المحلي فقط)
- `css/style.css` — الأنماط المخصصة الأصلية
- `css/tailwind.css` — Tailwind مبني محلياً (بديل CDN) بنفس الإعدادات
- `css/fonts.css` + `fonts/` — خطوط Tajawal وCairo محلية
- `js/lib/` — PDF.js 3.11.174 المحلية (`pdf.min.js` و`pdf.worker.min.js`)
- `assets/favicon.svg` — أيقونة جديدة أُنشئت للمشروع (لم تكن موجودة في الأصل)

## ملاحظة
زر «تصدير نسخة نهائية مدمجة بالكتاب» ينتج ملف HTML واحد يشير إلى css/js بمسارات نسبية، لذلك يجب إبقاؤه داخل هذا المجلد.
